# VoltVault

A responsive tech-gadget storefront built with React and Vite.

## Components
- `Header` — store branding and navigation
- `Hero` — featured storefront banner
- `ProductCard` — reusable product display populated with props
- `Footer` — store links and customer-support information

The homepage renders three product cards from a product data array in `App.jsx`.

**CSS attribution:** Styling was developed with assistance from ChatGPT (OpenAI), as permitted by the assignment instructions.
